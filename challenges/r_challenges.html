Introduction

Welcome to the Lost Lab Notebook challenge! This is my first attempt at creating a challenge like this. I put it together because I really love R, and I wanted to create something that helps others explore it in a fun, hands-on way. The idea behind The Lost Lab Notebook is to make learning feel like solving a mystery — where every line of code brings you closer to uncovering the story. I hope you enjoy working through the puzzles as much as I enjoyed designing them!

This challenge is aimed at beginners who have a little bit of experience with R, especially if you’ve used ggplot2 or dplyr before. But don’t worry — you don’t need to be an expert! If you ever get stuck, feel free to use any resources

How it works

  • The code for each exercise is partially written — your job is to finish it off
  • You don’t need to import any libraries — they’re already loaded for you. These include dplyr, ggplot2, stringr, lubridate, janitor, tibble, tidyr, purrr, and magrittr. We believe these are more than enough to complete the challenges. However, if you feel like you need something else, you can contact me at maryna.shedzko@manchester.ac.uk
  • You’ll see some questions and coding exercises — try them out, and don’t worry if you need to retry
  • Everything runs in R right in your browser — just write and run code in the provided boxes
  • If you have any questions, please contact maryna.shedzko@manchester.ac.uk

What You’ll Practice

Throughout the challenge, you’ll:

  • Clean and filter messy datasets
  • Work with spatial and coordinate data
  • Manipulate strings and encoded text
  • Piece together a narrative from clues
