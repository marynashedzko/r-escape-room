# R Escape Room: The Lost Lab Notebook

This project is an interactive R programming challenge where you solve data science puzzles to uncover the mystery of a lost scientist's research.

## How to Run

1. Install R (version 4.0+) and RStudio.
2. Install the required R packages:

```r
install.packages(c(
  "dplyr", "ggplot2", "tidyr", "readr", "stringr", "purrr", "tibble",
  "learnr", "janitor", "lubridate", "magrittr", "base64enc", "rsconnect"
))
```

3. Open `r-escape-room.Rproj` in RStudio.
4. Open a challenge file (e.g. `challenges/r_challenges.Rmd`).
5. Click "Run Document" to launch the interactive tutorial, or knit to HTML.
